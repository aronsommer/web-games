# Cat Car

by Aron Sommer · engine: Unity 5.6 · added 2021-05-03 · last update unknown
CrazyGames rating: 8.5 (1284 up / 225 down)

## Description

Cat Car is a funny high-score driving game in which you play as Cat Car. The time is running and you have to catch as many yellow balls as you can.

Avoid the red balls and have fun!

## Release Date

- October 2020 (Android and iOS)
- May 2021 (WebGL)

## Developer

Aron Sommer developed Cat Car.

## Platforms

- Web browser
- Android
- iOS

## Controls

- WASD or arrow keys to control your Cat Car
- Press spacebar to change camera view
- Press R key to reset to start position
