# Slope Car

by Aron Sommer · engine: Unity 2023 · added 2021-05-28 · last update 2024-10-04
CrazyGames rating: 8.5 (876 up / 149 down)

## Description

Slope Car is an arcade game to drive your car on a randomized slope and go as far as possible. This game is a combination of Crazy Roll 3D and driving a car.

## Release Date

June 2021

## Developer

Slope Car was made by Aron Sommer.

## Platforms

- Web browser
- Android
- iOS

## Controls

- AD / left and right arrow keys = steer
- W / up arrow key = boost
