# Hyper Jelly

by Aron Sommer · engine: Unity 5.6 · added 2018-05-07 · last update unknown
CrazyGames rating: 8.9 (893 up / 116 down)

## Description

Hyper Jelly is an awesome and fast-paced platform game in which you control a single jelly cube and must jump from one platform to the next. This might sound easy, but the 3D platforms and changing camera angle make this game tricky.

You must try and avoid the various obstacles on the platforms an do what you can to keep the jelly moving.

This is an endless game and you must simply see how far you progress and what high score you can register. Use the space bar to jump, and use the C key to change the angle of the camera. What high score can you register on Hyper Jelly?
