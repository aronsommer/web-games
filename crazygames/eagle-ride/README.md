# Eagle Ride

by Aron Sommer · engine: Unity 2023 · added 2019-10-02 · last update 2024-06-10
CrazyGames rating: 9 (3622 up / 402 down)

## Description

Eagle Ride is a very challenging flying game where you ride a fast-flying eagle, avoiding trees. Thankfully, it is a bright day with only a little bit of fog so that you can see very clearly.

The eagle's flying speed is very hig,h and you need to avoid the trees swiftly. If you hit one, you can always restart and try again. What is the longest time you can fly without crashing? Good luck!

## Release Date

November 7, 2017 (prototype), and has been updated in October 2019 (full version).

## Developer

Aron Sommer developed Eagle Ride and can be played online at CrazyGames.com. A Japanese composer, Hideyuki Fukasawa, made the music.

## Features

- High difficulty
- 3D environment
- Easy controls
- Four game modes: Classic, Crazy, Hardcore, and Cat Car

## Platforms

- Desktop browser
- Android
- iOS

## Controls

- Left and right arrow keys = steer
- Space bar = replay
